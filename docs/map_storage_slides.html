3D Mapping · Golf Cart ROS2

การเก็บ Map คือการรวมข้อมูล LiDAR, IMU, GPS/RTK และความเร็วล้อให้กลายเป็นแผนที่จุด 3 มิติ

ระบบนี้ใช้ LIO-SAM เป็นแกนหลัก สร้าง pose ของรถระหว่างวิ่ง แล้วสะสม point cloud ที่จัดแนวแล้วเป็น global map สำหรับ localization ภายหลัง

1

LiDAR Ouster

ส่ง point cloud เข้า topic /ouster/points เป็นรูปทรงของถนน ต้นไม้ อาคาร และสิ่งกีดขวางรอบรถ

2

IMU + Speed

IMU ใช้คาดการณ์การหมุนและการเคลื่อนที่ ส่วน /speed_status ช่วยกด drift ตอนรถนิ่งหรือวิ่งช้า

3

GPS/RTK

รับ fix จาก u-blox และ correction จาก NTRIP เพื่อยึด map กับตำแหน่งจริง ลดการลอยสะสมเมื่อวิ่งระยะไกล

4

LIO-SAM Map

จัดแนว scan ต่อ scan เพิ่ม keyframe ทำ loop closure แล้วเก็บเป็น point cloud map ในหน่วยความจำ

Topic หลัก: /ouster/points, /ouster/imu, /ublox_gps_node/fix, /gps_odom, /speed_status หน้า 1/3
สิ่งที่เกิดขึ้นระหว่างวิ่งเก็บแผนที่

LIO-SAM ไม่ได้ “บันทึกไฟล์” ตลอดเวลา แต่สร้าง map ที่ปรับแก้แล้วอยู่ในหน่วยความจำก่อน

1. แปลงข้อมูลดิบเป็น scan ที่พร้อมจับคู่

  • กรองระยะ LiDAR โดยใช้ช่วงประมาณ 2-40 เมตร เพื่อลด noise ใกล้ตัวรถและจุดไกลที่ไม่นิ่ง
  • แยก edge/surface feature แล้วใช้ IMU ช่วยแก้การบิดเบี้ยวของ scan ขณะรถเคลื่อนที่

2. สร้าง pose และ keyframe

  • scan-to-map optimization หาตำแหน่งรถในกรอบ map
  • เพิ่ม keyframe เมื่อรถเคลื่อนที่พอสมควรหรือเลี้ยวชัดเจน เพื่อให้ map มีความละเอียดพอ

3. ปรับ map ให้แน่นขึ้น

  • เปิด loop closure เพื่อดึงปลายทางที่กลับมาซ้ำให้ตรงกับรอบก่อน
  • ใช้ GPS/RTK เป็น global anchor เมื่อ covariance ดีพอ ลด drift สะสมของเส้นทางยาว
Voxel map downsample จุดให้ขนาดพอดี ใช้ leaf size ระดับ 0.15-0.2 เมตร
Loop closure ตรวจจุดที่เคยผ่านแล้ว เพื่อดึง map ให้ปิดรอบได้ตรงขึ้น
Dynamic removal ลบวัตถุชั่วคราวตอน save เช่น คน รถ หรือสิ่งที่ผ่านไปแล้ว
Transient filter เก็บจุดที่ถูกเห็นหลาย keyframe เพื่อให้เหลือโครงสร้างถาวร
หลักคิด: วิ่งซ้ำเส้นเดิมช่วยให้ loop closure และ dynamic removal ทำงานดีขึ้น หน้า 2/3
การบันทึกและนำ map ไปใช้

เมื่อกดบันทึก ระบบเรียก service ของ LIO-SAM แล้วเขียน GlobalMap.pcd ลงโฟลเดอร์ปลายทาง

คำสั่งที่ปุ่ม “บันทึกแผนที่” ใช้

ใน RViz panel ปุ่มจะเรียก service /lio_sam/save_map พร้อมกำหนด resolution และ destination

ros2 service call /lio_sam/save_map lio_sam/srv/SaveMap "{resolution: 0.2, destination: '~/Downloads/LOAM'}"

ไฟล์ผลลัพธ์หลัก

  • ~/Downloads/LOAM/GlobalMap.pcd คือแผนที่ point cloud ที่นำไปใช้ localization
  • หลังจากนั้น stack ขับรถจะใช้ GlobalMap.pcd เป็นแผนที่อ้างอิงสำหรับ NDT localization และ publish pose ออกที่ /pcl_pose

ข้อควรระวังตอน save

  • map ระหว่างวิ่งอยู่ในหน่วยความจำ ถ้าหยุด LIO-SAM ก่อน save รอบนั้นจะหาย
  • service save จะลบโฟลเดอร์ปลายทางก่อนเขียนใหม่ จึงควรคัดลอก map เก่าออกถ้ายังต้องใช้
  • ถ้า savePCD: true อยู่ใน params ตอนปิด LIO-SAM อาจเขียน map ใหม่ทับโฟลเดอร์เดิม

Checklist หลังบันทึก

  • ตรวจว่า GlobalMap.pcd ถูกสร้างใหม่และขนาดไฟล์สมเหตุสมผล
  • เปิดดูใน RViz หรือเครื่องมือ PCD viewer ว่า map ไม่บิด ไม่ซ้อน และไม่มีวัตถุชั่วคราวมากเกินไป
  • ทดสอบ localization โดยรัน stack แล้วดูว่า /pcl_pose publish ได้ต่อเนื่อง
สรุป: วิ่งให้ครบเส้นทาง → ตรวจ map ใน RViz → กดบันทึก → สำรอง GlobalMap.pcd → ทดสอบ localization หน้า 3/3
